# Конфигурация `TFT_config.h`

Для настройки библиотеки скопируйте шаблон `TFT_config_Template.h` в папку заголовков вашего проекта (например, `Core/Inc/`) под именем `TFT_config.h`.

---

## 1. Аппаратные интерфейсы

```cpp
#define TFT_USE_SPI   // Включает поддержку шины SPI (ST7789, ILI9225, SSD1306-SPI)
#define TFT_USE_I2C   // Включает поддержку шины I2C (SSD1306-I2C)
```

> [!NOTE]
> Макрос пишется с латинской буквой `C`. Старое написание с кириллической `С` поддерживается для обратной совместимости, но не рекомендуется.

---

## 2. Выбор контроллера экрана (активен должен быть один)

```cpp
//#define TFT_DRIVER_SSD1306
//#define TFT_DRIVER_ILI9225
#define TFT_DRIVER_ST7789
```

* **`TFT_DRIVER_ST7789`** — цветные IPS/TFT дисплеи с разрешением 135x240, 240x240, 240x320.
* **`TFT_DRIVER_SSD1306`** — монохромные OLED 128x64 / 128x32.
* **`TFT_DRIVER_ILI9225`** — цветные TFT дисплеи 176x220.

---

## 3. Глубина цвета фреймбуфера

```cpp
//#define TFT_USE_1BIT   // 1 бит на пиксель (OLED, монохром)
//#define TFT_USE_4BIT   // 4 бита на пиксель (16 цветов по палитре, 2 пикселя в байте)
//#define TFT_USE_8BIT   // 8 бит на пиксель (256 цветов)
#define TFT_USE_16BIT  // 16 бит на пиксель (RGB565, 65k цветов)
```

### Автоматический fallback:
Если в `TFT_config.h` закомментированы все 4 макроса глубины цвета, `TFT_define.h` автоматически активирует поддержку всех вариантов (`1, 4, 8, 16 бит`). При этом фактический режим определяется значением поля `LCD->Bit` дескриптора экрана во время работы программы.

### Оптимизация скорости (Single-bit mode):
```cpp
//#define TFT_USE_ONLY_ONE_BIT_COLOR
```
Если проект использует строго одну глубину цвета, раскомментируйте этот макрос. Проверки `if (LCD->Bit == ...)` перестанут генерироваться, что уменьшит размер бинарного кода и ускорит вызовы `SetPixel` и `GetPixel`.

## 5. Настройка DMA для ST7789

### Блочный DMA (`ST7789_UpdateDMA16bitV3`):
Функция использует неблокирующую отправку фреймбуфера частями по 65 534 байта и ожидает флаг `DMA_TX_Complete`. 
В вашем проекте **обязательно** должен быть объявлен колбэк HAL:

```cpp
extern "C" void HAL_SPI_TxCpltCallback(SPI_HandleTypeDef *hspi) {
    // Укажите hspi вашего дисплея
    if (hspi == &hspi1) {
        tft.driver.DMA_TX_Complete = 1;
    }
}
```

> [!WARNING]
> Без реализации `HAL_SPI_TxCpltCallback` вызов функций `ST7789_UpdateDMA*` зависнет в бесконечном цикле ожидания флага.

### Кольцевой циклический DMA (`ST7789_Update_DMA_Cicle_On` / `Off`):
Используется для постоянного фонового обновления экрана с нулевой нагрузкой на процессор. Привязка к DMA и SPI происходит динамически через дескриптор `LCD->hspi->hdmatx` (работает на любом канале SPI и DMA). При включении автоматически опускается пин `CS_0`, а при выключении — поднимается `CS_1`.
