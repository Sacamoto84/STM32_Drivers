# Спрайты и геометрические трансформации (`Sprites & Transformation`)

Спрайт — это виртуальный экран в оперативной памяти (`SPRITE_RAM`), для которого доступны абсолютно все функции отрисовки класса `TFT`: примитивы, растровые изображения и шрифты. Сформированный в спрайте кадр можно затем быстро скопировать на физический экран, наложить с прозрачным цветом, повернуть на произвольный угол или проскроллить.

---

## 1. Создание спрайта в памяти

Для создания 16-битного спрайта используется макрос `CREATE_SPRITE16`:

```cpp
#include "TFT.h"
#include "Transformation/transformation.h"

// Создание буфера и дескриптора спрайта размером 32x32 пикселя
CREATE_SPRITE16(SprIcon, 32, 32);

// Создаем экземпляр TFT для управления спрайтом
TFT sprite;

void InitSprite(void) {
    // Привязываем спрайт к объекту TFT
    sprite.init(&SprIcon);

    // Рисуем графику внутри спрайта
    sprite.Fill(BLACK);
    sprite.CircleFilled(16, 16, 14, YELLOW);
    sprite.CircleFilled(11, 12, 3, BLACK); // Глаза
    sprite.CircleFilled(21, 12, 3, BLACK);
    sprite.Line(10, 22, 22, 22, RED);     // Улыбка
}
```

## 2. Перенос спрайта на экран

### Прямое копирование (`copy`):
Копирует прямоугольный буфер спрайта в заданные координаты `x, y` на целевом экране (с автоматическим отсечением за границами экрана):

```cpp
tft.copy(&sprite, 50, 60);
```

### Копирование с прозрачностью (`copyTr`):
Пиксели спрайта, цвет которых совпадает с ключевым цветом `trColor`, не перезаписывают пиксели экрана:

```cpp
// Все черные пиксели (BLACK) спрайта будут прозрачными
tft.copyTr(&sprite, 50, 60, BLACK);
```

## 3. Произвольное вращение спрайта (`transformation::pushRotated`)

Класс `transformation` (`Transformation/transformation.h`) позволяет поворачивать спрайт на любой угол с субпиксельной интерполяцией и автоматическим расчетом габаритов (*bounding box*).

```cpp
transformation trans(&tft);

// Точка вращения внутри самого спрайта (локальные координаты)
sprite._xPivot = 16;  // Центр спрайта 32x32
sprite._yPivot = 16;

// Точка на экране, вокруг которой будет происходить вращение
tft._xPivot = 67;     // Центр экрана 135x240
tft._yPivot = 120;

int16_t angle = 45;   // Угол в градусах (0..359)

// Отрисовка повернутого спрайта с прозрачным фоном BLACK
trans.pushRotated(&tft, &sprite, angle, BLACK);
```

> [!TIP]
> Точка вращения `_xPivot` / `_yPivot` может выходить за пределы спрайта (например, отрицательные координаты для стрелок приборов или маятников).

## 4. Аппаратный и программный скроллинг (`scroll`)

Класс `transformation` позволяет выполнять сдвиг пикселей в заданной прямоугольной зоне экрана или спрайта (идеально для построения графиков и бегущих строк в реальном времени):

```cpp
transformation transSpr(&sprite);

// 1. Задаем прямоугольную область для скроллинга и цвет очистки освободившегося края
transSpr.setScrollRect(0, 0, 32, 32, BLACK);

// 2. Сдвигаем область на 1 пиксель влево (dx = -1, dy = 0)
transSpr.scroll(-1, 0);

// 3. Дорисовываем новую точку графика на правом краю
sprite.SetPixel(31, newGraphValue, GREEN);

// 4. Отображаем обновленный спрайт на дисплее
tft.copy(&sprite, 10, 10);
```
