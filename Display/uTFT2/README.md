# uTFT2 — Графическая библиотека для STM32

**uTFT2** — быстрая, модульная C++ графическая библиотека для микроконтроллеров STM32. Библиотека работает через кадровый буфер (framebuffer) в оперативной памяти, поддерживает различные глубины цвета (от 1 до 16 бит), аппаратное ускорение через SPI / I2C / DMA, спрайты с альфа-каналом и вращением, богатый набор шрифтовых движков, анимации и воспроизведение медиа с SD-карты.

---

## Ключевые возможности

* **Аппаратные драйверы экранов:**
  * **ST7789** — SPI (8/16 бит), попиксельный/построчный вывод, блочный DMA (`UpdateDMA16bitV3`), кольцевой непрерывный DMA (`Update_DMA_Cicle_On/Off`).
  * **SSD1306** — I2C (через `HAL_I2C_Mem_Write`) и SPI, поддержка монохромных дисплеев (OLED 128x64, 128x32).
  * **ILI9225** — SPI, цветные TFT-дисплеи (176x220).
  * **SPRITE_RAM** — виртуальный дисплей в ОЗУ (off-screen канва для формирования кадров, композитинга и трансформаций).
* **Глубина цвета фреймбуфера:**
  * **16 бит** (RGB565, 65 536 цветов) — максимальное качество цветопередачи.
  * **8 бит** (256 цветов / палитра) — баланс памяти и цветности, оптимизированная очистка через `memset`.
  * **4 бита** (16 цветов с палитрой `palete[]`, 2 пикселя на байт) — сверхэкономичный режим, корректный расчёт шага строки (*stride*) для нечётных разрешений (например, 135x240).
  * **1 бит** (монохром, 8 пикселей на байт) — для OLED и экономии ОЗУ.
  * Флаг `#define TFT_USE_ONLY_ONE_BIT_COLOR` для компиляции без рантайм-проверок глубины цвета (максимальная скорость).
* **Графические примитивы (`TFT_Primitive`):**
  * Точки (`SetPixel`, `GetPixel`), быстрые линии (Брезенхем, вертикальные `LineV`, горизонтальные `LineH` с клиппингом).
  * Прямоугольники (`Rectangle`, `RectangleFilled` с клиппингом по 4 сторонам), инверсия (`InvertRectangle`), замена цвета в области (`ChangeColorRectangle`).
  * Окружности (`Circle`, быстрая заливка `CircleFilled` горизонтальными сканирующими линиями).
  * Треугольники (`Triangle`, `TriangleFilled`), вертикальные градиенты (`Gradient_Vertical`).
* **Спрайты и геометрические трансформации (`Transformation`):**
  * Отрисовка в буфер спрайта в памяти (`CREATE_SPRITE16`).
  * Наложение спрайтов на экран с прозрачным ключевым цветом (`copyTr`).
  * Произвольное вращение спрайтов (`transformation::pushRotated`) с настраиваемыми точками опоры (`_xPivot`, `_yPivot`).
  * Аппаратный/программный скроллинг прямоугольных областей (`scroll`).
* **Шрифтовые подсистемы:**
  * **FontGFX** — пропорциональные шрифты в стиле Adafruit GFX, поддержка кириллицы (UTF-8), настраиваемый межсимвольный интервал `delta_x`, обработка `\n`.
  * **FontSmooth** — сглаженные шрифты формата `.vlw` с альфа-блендингом (4bpp), безопасная работа на любой битности экрана.
  * **FontClassic** — моноширинные растровые шрифты (`Font_7x10`, `Font_11x18`, `Font_16x26`), перенос строк `\n`.
  * **FontMicroElectronika** — шрифты MikroElektronika (латиница и кириллица cp1251), расчет точной длины строки `FontMicroFindLenStr(..., dx)`.
* **Растровые изображения и анимация:**
  * Из Flash: 16 бит (RGB565), 24 бит, 32 бит (с альфа-каналом), 1 бит, прозрачные спрайты, оптимизированное заполнение фона 32-битными словами.
  * С SD-карты (FatFs): чтение файлов BMP (16, 24, 32 бит).
  * **GIF-анимация** (`Animated/Gif.h`): покадровое воспроизведение с контролем задержек кадра (`uwTick`).
  * **EasingProvider** (`Animated/EasingProvider.h`): математические кривые плавности (Linear, Quad, Cubic, Sine, Bounce, Elastic и др.).

## Быстрый старт

### 1. Подключение к проекту STM32
Скопируйте папку `uTFT2` в ваш проект (например, в `Drivers/Display/uTFT2` или `Middlewares/uTFT2`).

Библиотека использует стандартный STM32 HAL, поэтому в путях поиска include проекта должны быть доступны:
* `main.h`
* `spi.h` (при использовании SPI)
* `i2c.h` (при использовании I2C)
* `fatfs.h` (при включении модуля `FAT_FS`)

### 2. Конфигурация `TFT_config.h`
Скопируйте `TFT_config_Template.h` в папку `Inc/` (или `Core/Inc/`) вашего проекта под именем `TFT_config.h` и включите необходимые параметры:

```c
#ifndef INC_TFT_CONFIG_H_
#define INC_TFT_CONFIG_H_

// Интерфейсы
#define TFT_USE_SPI
//#define TFT_USE_I2C

// Драйвер (выбрать один)
#define TFT_DRIVER_ST7789
//#define TFT_DRIVER_SSD1306
//#define TFT_DRIVER_ILI9225

// Глубина цвета фреймбуфера
#define TFT_USE_16BIT

#endif /* INC_TFT_CONFIG_H_ */
```

### 3. Описание и инициализация экрана

В вашем файле приложения (например, `main.cpp`):

```cpp
#include "main.h"
#include "TFT.h"

// Создаем экземпляр экрана
TFT tft;

// Буфер фреймбуфера в ОЗУ (для 135x240 16-бит = 64 800 байт)
uint16_t framebuf[135 * 240];

// Описание параметров экрана ST7789
TFT_LCD_t LCD_0 = {
    .TFT_WIDTH       = 135,
    .TFT_HEIGHT      = 240,
    .LCD_Driver      = ST7789,
    .Bit             = 16,
    .hspi            = &hspi1,
    .hi2c            = NULL,
    .I2C_Adress      = 0,
    .buffer16        = framebuf,
    .buffer8         = NULL,
    .palete          = NULL,
    .dx              = 52,
    .dy              = 40,
    .GPIO_CS         = LCD_CS_GPIO_Port,
    .GPIO_Pin_CS     = LCD_CS_Pin,
    .GPIO_DC         = LCD_DC_GPIO_Port,
    .GPIO_Pin_DC     = LCD_DC_Pin,
    .GPIO_RESET      = LCD_RST_GPIO_Port,
    .GPIO_Pin_RESET  = LCD_RST_Pin,
};

int main(void) {
    // Инициализация HAL, тактирования, GPIO и SPI...
    HAL_Init();
    SystemClock_Config();
    MX_GPIO_Init();
    MX_SPI1_Init();

    // Инициализируем TFT
    tft.init(&LCD_0);

    // Рисуем графику
    tft.Fill(BLACK);
    tft.RectangleFilled(10, 10, 115, 40, NAVY);
    tft.Rectangle(10, 10, 115, 40, WHITE);
    tft.CircleFilled(67, 120, 30, RED);

    // Отправляем буфер на дисплей
    tft.driver.ST7789_Update();

    while (1) {
    }
}
```

## Работа с DMA (ST7789)

Для использования неблокирующего обновления через DMA (`ST7789_UpdateDMA16bitV3`):

1. В STM32CubeMX для используемого SPI добавьте **SPI_TX DMA Stream**.
2. В коде определите колбэк прерывания передачи:
```cpp
extern "C" void HAL_SPI_TxCpltCallback(SPI_HandleTypeDef *hspi) {
    if (hspi == &hspi1) {
        tft.driver.DMA_TX_Complete = 1;
    }
}
```
3. Вызывайте обновление кадра:
```cpp
tft.driver.ST7789_UpdateDMA16bitV3();
```
