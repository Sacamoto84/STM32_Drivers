Библиотека TFT создана для экранов SSD1306(I2C, SPI), ILI9225, ST7789, USB эмуляция, SPRITE_RAM
Работа через буффер фрейма, поддерживается вывод в 1, 4, 8, 16 бит цвете
С++ проект

Реализованные драйверы: **SSD1306, ILI9225, ST7789**.
ST7735/ST7735S/PCD8544 объявлены в enum, но реализаций в библиотеке нет.
SPRITE_RAM - RAM-канва без аппаратного обновления (Update() ничего не делает).
